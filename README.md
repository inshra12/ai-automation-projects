# AI Automation Projects

A collection of AI-powered automation workflows built with Zapier and Google Gemini.

---

## Project 1: PubMed Research Paper Monitor

### What it does
Automatically monitors PubMed for new computational biology papers, 
summarizes them using Google Gemini AI, logs them to Google Sheets, 
and sends email notifications.

### Tools Used
- Zapier
- PubMed RSS Feed
- Google Gemini API
- Google Sheets
- Gmail

### Workflow
PubMed RSS → Gemini AI Summary → Google Sheets → Gmail Notification

### Use Case
Built for researchers who want to stay updated on new papers 
without manually searching PubMed every day.
